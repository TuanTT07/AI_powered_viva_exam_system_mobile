# UI states

ready: seeded data. loading: indicator and exit simulation action. empty: explanation and sample action. error: simulated connection failure and retry.

Student: idle, empty validation, unknown code, found personal slot. Lecturer: empty filtered results, read-only cancelled slot, edit errors, review, successful local update.

Controls have >=48dp hit areas, accessible labels, text status cues and contrast. Verify keyboard, large font, system Back and screen rotation on Android independently of browser tests.
