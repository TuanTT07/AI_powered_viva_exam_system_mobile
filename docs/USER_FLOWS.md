# User flows

Welcome → Đăng nhập → real POST /api/auth/login → route by backend STUDENT/LECTURER role. Email/password form supports pending, invalid-input, invalid-credential, timeout/network and unsupported-role feedback. Android Back on sign-in returns to Welcome unless a request is pending. No role-selection bypass.

Account requires password change → gated ChangePasswordScreen → confirmed POST /api/auth/change-password → clear saved session → sign in again for a new JWT. Normal password change is accessible from profile/account actions. No password recovery endpoint is invented.

Startup with saved token → GET /api/auth/me → verified role/user. Expired/invalid token → sign in again. Transient network failure → recoverable verification screen, preserving stored token until retry or explicit re-authentication. Đăng xuất removes saved token; Android Back at feature root leaves/backgrounds the app without signing out.

- Sinh viên: Lịch thi (Sắp tới / Đã qua) → chi tiết ca, mã phòng thi (accessCode), câu hỏi cấp phát; Điểm → GET /api/v1/student/exams/{attemptId}/results cho ca đã hoàn tất → danh sách mã môn + điểm trung bình /10 (quy đổi từng câu theo finalScore/maxScore rồi lấy trung bình) → chạm để xem chi tiết điểm từng câu và nhận xét giảng viên (3 dòng, mở đầy đủ); hỗ trợ đang tải, lỗi/thử lại và kéo để làm mới; Hồ sơ → actual user name/code/email, password change and logout. Đã kết nối API backend thật (/api/v1/student/exams, /api/v1/student/exams/{examId}/my-slot, /api/v1/exams).
- Giảng viên: Lịch coi thi (Sắp tới / Đã qua kèm bộ lọc trạng thái Tất cả, Sẵn sàng, Đang thi, Vắng mặt, Hoàn tất) → bảng theo dõi tiến độ kỳ thi (tổng số thí sinh, sẵn sàng, đang thi, hoàn tất, vắng mặt, tỷ lệ %); Chuyển trạng thái kỳ thi (IN_PROGRESS / COMPLETED); Chi tiết ca thi → thao tác ghi nhận vắng thi, reset ca thi, và đổi lịch ca thi (reschedule); Danh sách thi → tìm kiếm thí sinh theo tên/mã kết hợp lọc theo trạng thái ca thi; Điểm thi → chọn môn học phụ trách, lọc theo trạng thái (Tất cả, Chờ duyệt, Đã chốt), xem chi tiết điểm AI gợi ý, điểm chính thức, tiêu chí rubric và nhận xét tổng thể; Hồ sơ → môn học phụ trách, actual user name/code/email, password change and logout. Đã kết nối API backend thật (/api/v1/exams, /api/v1/exams/{examId}/schedule, /api/v1/exams/{examId}/monitor, /api/v1/exams/{examId}/schedule/reschedule, /api/v1/exams/{id}/status, /api/courses/{courseId}/evaluations, /api/question-attempts/{questionAttemptId}/evaluation, /api/lecturers/{lecturerId}/courses).

Authentication, Giảng viên API (Lịch coi thi & Điểm thi) và Sinh viên Lịch thi API đã được kết nối với backend thật. Không có bản ghi mẫu hoặc kết quả giả mạo nào sau khi đăng nhập.
